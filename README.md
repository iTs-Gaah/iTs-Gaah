Profissional focado em governança, qualidade e integridade de bases complexas. Minha especialidade é transformar bases operacionais caóticas e fragmentadas em dados limpos, confiáveis e estruturados para a tomada de decisão rápida e segura.

### 🎯 O que eu faço:
* **Master Data Management (MDM):** Saneamento e cruzamento de grandes volumes de dados, caçando inconsistências na raiz e garantindo a integridade sistêmica (ERPs).
* **Automação de Processos:** Desenvolvimento de bots e scripts em Python para aniquilar rotinas braçais, conectar APIs e mitigar falhas humanas na operação.
* **Governança:** Estruturação de pipelines e dashboards com controle de acesso rigoroso para garantir uma *Single Source of Truth* (Fonte Única de Verdade).
